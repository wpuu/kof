# 商业化、内容版权及用户权益准入矩阵

编制：2026-10-25。研究结论不构成法律意见。

## 直接决策
- **禁止路径：**没有相应授权就在境外网站提供 KOF ROM、改造版、游戏云串流或衍生素材，并通过广告、VIP、打赏、时长卡等间接变现。服务器在国外、未备案、个人经营、用户无须“手动下载 ROM”都不会自动消除版权问题。
- **研究路径 A：**围绕既有合法 KOF 客户端开展*独立*约战、赛程、玩家社区与原创教程；不分发游戏程序，不冒充 SNK 官方，并核清商业赛事/直播/商标/图片使用边界。
- **研究路径 B：**以明确商用授权的原创网页格斗内容提供浏览器即玩体验，会员价值来自服务与外观，而非有价投注。
- **未来选项：**向游戏权利人申请具体用途授权，书面覆盖游戏提供形式、地区、平台、直播/收费方式和许可期限。

## 事实来源
- [SNK 官方软件条款](https://www.snk-corp.co.jp/us/guide/terms/)：符合条件的个人游戏视频及认可平台收益，不等于允许自行分发付费 KOF 网页游戏。
- [SNK eSPORTS Support Program](https://www.snk-corp.co.jp/sesp/eng/)：官方支持满足要求的线上/线下赛事，个人也可申请，公开门槛至少16人；它不是永久或完整游戏内容许可。
- [国家新闻出版署网络出版审批](https://www.nppa.gov.cn/bsfw/xksx/cbfxl/wlcbfwspsx/202210/t20221013_600723.html)：商业提供网络游戏需进一步审查出版审批、运营主体及相关资质；引擎 MIT 不等于可以无资质收费经营。
- [Tough Love Arena 官方](https://about.toughlovearena.com/)：免费浏览器格斗和付费版本/高级外观并行的实际参照，不保证本项目可复制其用户留存或盈利。
- [MDN WebRTC ICE](https://developer.mozilla.org/en-US/docs/Glossary/ICE)：TURN 备用必要性与 P2P 连接条件。

## 独立审查矩阵
| 模块 | 上线前必须确认 | 当前状态 |
|---|---|---|
| KOF ROM / 音视频 / 游戏角色 | 权利人具体商业许可 | **未取得，不提供** |
| 开源源码 | 仓库逐项许可证和第三方依赖 | 只读初查完成，未清单式全面审计 |
| 游戏图片/人物/音乐 | 素材级商用许可，必要时替换为原创 | 待验证；Aether Clash 资产明确非商用 |
| 中国大陆收费网络游戏 | 出版/运营审批及游戏合规咨询 | 未完成 |
| 会员功能、积分及 2→1 兑换 | 真实价格、服务成本、退费和交付规则 | 模型阶段 |
| 观众下注/付费天数转移 | 涉赌、支付及消费者保护评估 | **冻结上线**；允许非可兑付积分的交互原型 |
| 游戏输赢自动判定 | 服务端可信结果、纠纷处理与异常监测 | Neon Fist 的双方同意校验不足以证明可信 |
| 账户和日志 | 登录、数据最小化、权限、留存政策 | 未完成 |

## 建议优先验证收入（假设，不是市场证据）
- 玩家会员：高级战绩分析、训练记录、赛事管理、个性化服务。
- 主播赛事工具：报名、排程、催场、赛程页、OBS 比分牌、战报、回放索引。
- 取得适用权利后：原创游戏外观或正式付费客户端。
- 设备推广：公开合规导购与佣金业务。
- **不把平台内天数销毁当作新现金收入；不把每场名义流水重复记收入。**

## 立项约束
先取得真实用户留存和明确愿付费证据，再投入复杂联机、服务器中继和完整游戏角色团队。若没有授权、不能通过同网和异网真机，或无法证明玩家体验，先暂停商用发布。
